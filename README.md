## What's inside

- `docs/` — practice notes
- Typical exercises: feature branches, pull requests, conflict resolution, merge vs. rebase

## How to practice

```bash
git checkout -b feature/try-1
# make some changes, then:
git add . && git commit -m "try: something new"
git push -u origin feature/try-1
# open a Pull Request on GitHub, review, then merge
```

# Pull request workflow

1. Create a branch from the latest `main`.
2. Make a focused change and commit it with a descriptive message.
3. Open a pull request describing the change and how it was checked.
4. Inspect the diff and verify that it contains only the intended changes.
5. Merge the pull request, then delete the completed branch.

## Practice exercise

This repository uses a documentation-only change to practice the full workflow.
The repository owner can merge this exercise without a separate reviewer.
For shared projects, follow the repository's review and branch protection rules.
